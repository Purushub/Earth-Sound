# 🌍 Earth Physics Lab — Two-Team 3D Gamified Battle Arena

An interactive, competitive 3D learning simulation activity for **Unit 06: Earth Physics**, featuring real-time Three.js physics visualizers, competitive dual-team buzzer mechanics, and the **Terra Guardian Mascot** interactive feedback system.

---

## 🌟 Key Features

### 1. Dual-Sided Team Layout (Zero Center Obstruction)
- **Clear 3D Viewport**: The center screen is 100% open for full 3D simulation orbit and interaction.
- **Wave Riders (Team A — Left Column)**: Team sigil, live score, streak multiplier badge, and question console. Keyboard buzzer: **`A`**.
- **Echo Team (Team B — Right Column)**: Team sigil, live score, streak multiplier badge, and question console. Keyboard buzzer: **`L`**.
- **Tactile Steal Mechanics**: If a buzzing team answers incorrectly, the opponent team gets an immediate **Steal Opportunity**!

### 2. 5 Distinct 3D Earth Physics Simulations
1. **6.1 Sound Waves**:
   - 3D acoustic speaker with vibrating diaphragm.
   - Longitudinal air particle grid (24 cols × 6 rows × 4 depth) demonstrating genuine compressions and rarefactions.
   - Resonating tympanic eardrum receiver.
   - Frequency ($200\text{ Hz} - 900\text{ Hz}$) & Amplitude sliders, plus real-time Web Audio pitch tone synthesizer.
2. **6.2 Reflections of Sound**:
   - 3D sonar transceiver emitting amber incident wavefronts toward a barrier.
   - **Wave Bouncing Physics**: Incident waves strike the barrier and visibly bounce back as bright cyan reflected waves toward the receiver.
   - Receiver hydrophone ring pulses neon-green when returning echoes arrive.
   - **Hard Wall vs. Acoustic Foam**: Hard surface reflects 95% of waves; porous foam absorbs 95% of acoustic energy (zero bounce).
   - **Sonar Pulse Ping 🔊**: Launches an isolated pulse with live telemetry: $d = \frac{v \times t}{2} = 1,500\text{ m}$.
   - **Wall Distance Slider**: Interactively shift wall distance ($4\text{m} - 10\text{m}$) and see echo travel delay change.
3. **6.3 Structures of the Earth**:
   - 3D layered cutaway Earth: Continental/oceanic **Crust**, convective magma **Mantle**, liquid molten iron **Outer Core**, and solid super-dense **Inner Core**.
   - Dynamic looping geomagnetic dipole magnetic field lines generated by outer core convection.
   - Seismic shadow zone exploration (P-waves vs S-waves).
4. **6.4 Changes in the Earth**:
   - Dynamic tectonic stage featuring convergent plate subduction.
   - Volcanic mountain uplift with rising molten lava eruption particle fountains.
   - Interactive controls: "Trigger Earthquake ⚡" with camera tremor shake, and "Erupt Volcano 🌋".
5. **6.5 Solar and Lunar Eclipses**:
   - 3D celestial orrery: Radiant Sun emitting light, orbiting Earth, and tilted-orbit Moon.
   - Geometric **Umbra** (total shadow) and **Penumbra** (partial shadow) projection cones.
   - Toggle between **Solar Eclipse** (Sun — Moon — Earth) and **Lunar Eclipse** (Sun — Earth — Moon with Rayleigh-scattered blood-red coloration).

### 3. Terra Guardian Mascot Feedback Modal
- Displays the 3D Earth character with animated entry and floating physics.
- **Right Answer**: Celebratory green aura, congratulations, streak multiplier points award, and educational explanation.
- **Wrong Answer**: Protective shield defense, announces opponent steal chance with immediate buzzer focus.
- Auto-advancing timer bar with manual "Continue ➔" override.

### 4. Audio & Visuals
- Background soundtrack: `pixeltown-color-parade.mp3` with equalizer visualizer and volume control.
- Zero-latency Web Audio sound effects: buzzer click, ding fanfare, wrong dissonance, sonar ping, and clock countdown tick.
- Grand Championship trophy modal with fireworks confetti celebration upon completing all rounds.

## 🚀 Running the Project

### Option A: Standalone Instant Play (Zero Setup)
Open [`index.html`](./index.html) or [`activity.html`](./activity.html) directly in any modern browser, or serve with any static web server:
```bash
python -m http.server 8080
```
Then visit: `http://localhost:8080`

### Option B: Vite / React / TypeScript Development Server
```bash
npm install
npm run dev
```
